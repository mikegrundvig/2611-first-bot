Installs and links

Everything is free. Windows is what the team's laptops run; most of it works on a Mac too.

Every student laptop

GitHub DesktopNeeded

Clone, branch, commit, push and open pull requests without typing Git commands. Sign in with your GitHub account.

Java 25 (Eclipse Temurin JDK)Needed

Gradle needs a Java installed just to start. Download the Windows .msi, and in the installer turn on Set JAVA_HOME variable (it's off by default). Then close and reopen any terminal or editor.

IntelliJ IDEANeeded: this or VS Code

The Java editor most companies use. It understands the whole project, and our projects come with its run buttons ready. Wants 8 GB of memory or more.

WPILib 2027 installer (alpha 7)Or this

WPILib's own VS Code, with the Java and WPILib extensions already in it. Pick it instead of IntelliJ on a laptop with less memory. A plain VS Code works too: when you open the project it offers the Java and WPILib extensions; say yes, then restart VS Code once.

The course codeNeeded

Clone it in GitHub Desktop: File › Clone repository › URL, then https://github.com/mikegrundvig/2611-first-bot. Its first build downloads about 1 GB, so do it on good internet.

Git for WindowsOptional

Only for typing git commands in a terminal. GitHub Desktop brings its own Git.

Gradle itself doesn't need installing: gradlew.bat downloads the right Gradle the first time. It only needs the Java above to start.

The bench laptop (the one that drives the chassis)

Phoenix Tuner X PreviewNeeded

CTRE's tool for the motors, CANcoders, Pigeon and the CANivore: firmware, CAN IDs, factory defaults, live plots. The Preview is the version for the 2027 firmware (26.70.x); it installs next to the regular Tuner X.

AdvantageScope 2027 alphaUseful

Opens the robot's logs: graphs, the field, and the robot in 3D. Use the 2027 alpha (v27.0.0-alpha-6), which reads the 2027 logs.

2027 Driver StationLater

Drives the real robot once it has a Systemcore. On the bench, WPILib's simulator window enables the chassis instead.
