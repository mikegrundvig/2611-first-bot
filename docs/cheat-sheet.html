Robot Code Cheat Sheet

Windows commands. On a Mac or Linux, type ./gradlew for gradlew.bat.

One change, start to finish

  1. Pull the latest
  2. Make a branch
  3. Change the code
  4. Run it and test it
  5. Commit, with a note
  6. Push the branch
  7. Pull request: review and CI
  8. Merge into main

Gradle: build and run

gradlew.bat buildCompile and test everything
gradlew.bat testRun only the tests
gradlew.bat runStart it in the simulator
gradlew.bat run -PhwSimDrive the real chassis from this laptop (CANivore on USB, chassis on blocks)
gradlew.bat deploySend it to the robot

Start the program through Gradle, never with an editor’s Run link beside main.

Git: save and share

git clone <link>Copy a project down, the first time
git pullBring others’ commits down
git switch -c my-changeStart a new branch
git statusWhat changed, what’s ready to commit
git add .Include every change in the next commit
git commit -m "Limit the motor to 20%"Save a commit with its note
git pushSend your commits up to GitHub

The first push of a new branch: git push -u origin my-change. Then open the pull request on GitHub.

When something goes wrong

Red underline, build failsCompile error. Read the first error: it names the file and line.
JAVA_HOME is not setNo Java yet, or the terminal was open before Java was installed. Install Java 25 with Set JAVA_HOME turned on, then reopen the terminal.
wpiutiljni could not be loadedStarted without Gradle. Use gradlew.bat run.
CANivore … not seenCheck the USB cable and that Phoenix Tuner X lists the CANivore.
CAN frame not receivedWrong CAN ID, or the device has no power. Compare the IDs with Tuner X.
Enabled, nothing movesFactory-default the devices in Tuner X, and check their firmware.
Push rejectedSomeone pushed first: git pull, then push again.

Words

Compile
Translate your .java text into bytecode the computer runs
Library
Code someone else wrote that yours uses (WPILib, Phoenix)
Gradle
The build tool: downloads, compiles, tests, runs, deploys
Commit
A save point of the whole project, with a note
Branch
Your own line of commits; main always works
Pull request
“Please merge my branch”, reviewed by the team
CI
GitHub builds and tests every change on a clean computer
Deploy
Send the program onto the robot
